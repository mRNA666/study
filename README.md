# 脏金 / Dirty Gold

UE 5.7 + C++ 的第一人称「竞争挖金」原型：挖矿、在黑市赌工艺品的真假、和三个模拟对手抢同一批货。

---

## 玩法

- **下矿**：买开采权（4000 币）→ 一镐一镐把矿洞挖穿 → 背着矿石回营地卸货
- **卖金**：黑市老板压价收（价随抛售量下跌、随时间恢复），正规买家全价但每天有配额
- **赌货**：黑商柜台每天 8 件工艺品，报价虚虚实实；花 500 币找「听泉鉴宝」验一次真实含金量，
  再决定卖给黑市（自己报价，可能被当场识破）还是正规买家（必验、全价）
- **竞争**：三个性格不同的对手（铁头 / 独眼 / 疤脸）按各自现金水平抢柜台，资产进排行榜

## 技术点

| 主题 | 做法 |
|---|---|
| **实时可破坏地形** | SDF 隐式场描述矿洞，玩家每镐做球体布尔减法，Marching Cubes 重建三角面；单次挖掘重建 4~6 ms |
| **打包崩溃定位** | 打包版崩在 `FAudioDevice::CreateComponent ← SpawnSoundAtLocation ← PerformDig`；根因是命名空间作用域的 `TObjectPtr` 不是 GC 根 → 换 `TStrongObjectPtr`，并依赖 `UPROPERTY` 让 GC 走反射图 |
| **输入状态机** | 修「退出 UI 后角色永久走不动」：`SetIgnoreMoveInput(false)` 是**栈计数减一**而非清零，多处加减漏一次就永久锁死 → 改成每帧 `Reset` + 按状态绝对量写回 |
| **经济数值验证** | 货架价格的不变式「全买成本 ≥ 1.12 × 真实价值」，用脚本跑 4000 张分布验证（可套利 0/4000），再落成游戏内 `Exec` 命令做回归 |
| **Cook / 打包** | UE 的 Cook 是可达性驱动的，`LoadObject` 的字符串路径不会被扫到 → 配 `DirectoriesToAlwaysCook` 与 `MapsToCook`，关掉 `bCookAll` 控制包体 |

## 已知限制（都是刻意的）

- **仓库不带角色/场景美术资源**：`Content/Characters`（126 MB）和 `Content/Survival_Character`（1.35 GB）
  没有上传，所以第一人称角色**没有手、没有身体**。
  代码里做了**降级**：检测到第一人称网格缺失时，把相机从「head 骨骼」改挂到胶囊的眼睛高度，
  因此**移动、跳跃、挖矿、交易、HUD 全部正常**，只是看不到自己的手。
  想要完整的手部：在 UE 里 `Add Feature or Content Pack → First Person`，或在角色蓝图里指定任意人形骨骼网格。
- **商人是引擎自带的圆柱**（`/Engine/BasicShapes/Cylinder`），不依赖任何项目美术资源 —— 保证 clone 即可见。
- 目前只有 **Camp / Mine1** 两张地图。

## 键盘

| 键 | 作用 |
|---|---|
| WASD / 空格 | 移动 / 跳 |
| 鼠标左键 | 挖矿 |
