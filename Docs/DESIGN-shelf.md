## 4. 黑商报价 `DeclaredPurity`（玩家看到的那个）

**【v4 重写】报价现在决定卖价，所以它必须"像那么回事"，以吹为主：**

```
30% 概率：Declared = RealPurity                       ← 老实报价（这就是漏）
10% 概率：Declared = RealPurity × 随机(0.75 ~ 1.00)   ← 故意低报（大漏）
60% 概率：Declared = RealPurity × 随机(1.20 ~ 2.60)   ← 吹
上下限：[0.02, 1.00]
```

> 为什么要改：旧版是 ±15% 双向偏差，因为报价和价格脱钩，吹狠了没意义。
> 现在价格 = 报价算出来的值（见 §5），报价吹得多狠 = 他在你身上赚多少。

---

## 5. 买入价 —— **按报价算，再加他一笔利润**

**【v4 重写】价格必须和报价自洽**，否则玩家看到"报 60% 却卖得比报 30% 的还便宜"，直接失去信任：

```
ClaimValue = 标称金重 × DeclaredPurity × 1000        ← 他嘴上说的"这东西值多少"
Price      = ClaimValue × 当天黑市基础价 × 随机(1.05 ~ 1.30)
```

- `当天黑市基础价` = `BlackMarketDailyRate`（0.55~0.75，每天刷）→ **所以必须先定金价再刷货架**
- 加价 1.05~1.30 是他的毛利：他按 65% 收，按 65%×1.17 ≈ 76% 卖

**兜底约束（保证"全买必亏"）：**
```
若 ΣPrice < 1.12 × Σ(标称 × 真实含金量 × 1000)  →  整架按比例放大到刚好 1.12 倍
```

**验算（4000 张货架模拟）：**
```
全买 变现/成本   平均 0.887，最好 0.893，最差 0.646   →  能赚钱的张数 = 0 / 4000
单件能捡漏的比例 40.1%                                →  鉴定/挑货有意义
价格 / 报价金价  中位 0.94（10% 分位 0.80，90% 分位 1.09）→  看着就是"他说的价 ± 一点"
金像价格         中位 94,062 币（旧版 127k~382k，太离谱）
```

**真金配额：** `Σ(RealPurity × 标称) ≤ 0.52 × Σ标称`。超了就从最贵的往下压 `RealPurity`。（保留）

## 6. 卖出价

| 渠道 | 公式 | 验不验 |
|---|---|---|
| **黄金黑商** | 标称 × **你报的**含金量 × 1000 × 0.65 × **0.95** | 按好感度概率验 |
| **正规买家** | 标称 × **真实**含金量 × 1000 × **1.00** | **100% 验** |

**黑商警告语：**「我这可是会验含量的，你小子不要骗我」

**报价框预填：** 鉴定过 → 真实值；没鉴定过 → 黑商当初的报价。

**正规买家 `MinDay = 2`** → 第一天只能卖黑商（工艺品的"先赌后学"节奏）。工艺品**可以一直囤着**，不强制当天卖。

## 7. 好感度（双向）

| 项 | 值 |
|---|---|
| 范围 / 初始 | 0–100 / **50** |
| **每卖给他 5 g 黄金** | **+1**（上限 100） |
| 被当场识破 | **−15** |
| 作用 | 决定黑商"验不验你"；PRD 原设计里还决定收购价系数 |

**被验概率：**
```
p = 0.72 − 0.0052 × 好感度 + max(0, 报价 − 真实) × 1.5
```
（好感 100 → 20%；好感 0 → 72%；虚报越多越容易被验）

```
[ 收金 ]  [ 购买工艺品 ]  [ 算了 ]
              ↓
┌──────────────────────────────┬─────────────────────┐
│ 柜台上的货（8 行，可点）        │ 今天谁买走了什么      │
│ 1. 金锁    25 g   约 9,800     │ · 独眼 买走了 金杯    │
│ 2. 金面具  40 g   约 31,200    │ · 疤脸 买走了 金像    │
│ 3. 金蛋    35 g   ⬛ 已买走     │                     │
│ 4. 金蟾    90 g   约 41,400    │                     │
│ ...                          │                     │
└──────────────────────────────┴─────────────────────┘
   ↓ 点某件
确认框：金蟾 / 标称 90 g / 价格 41,400 / 黑商报含金量 61%
话术：「船上掉的货，不图钱」
   [ 买下 ]  [ 算了 ]
```

## 9. 交互流程 B：抢货（模拟对手）

**不是一次性结算，而是随时间随机发生**（和对手的上矿节奏一致）：

```
每个对手的「买货」是它状态机里的一个动作，和上矿/卖货并列：
  轮到它行动时，有 25% 概率先去柜台看看
    独眼（赌）：看中就买 —— 从没被买走的里随机挑 1 件
    铁头（稳）：只买「标称 60 g 以下」的便宜货
    疤脸（囤）：只买「标称 250 g 以上」的大件
买走 → bSold = true，该行变暗不可点，右侧记一行「独眼 买走了 金杯」
时间随机 → 你可能刚看完就被抢，也可能一整局都没人碰
```

## 11. 交互流程 D：听泉鉴宝（新 NPC）

**它是一个 `AMerchant`，`Kind = Appraiser`。你在关卡里摆一个，设好 Kind 即可。**

```
靠近 → E
   ↓
[ 鉴宝 ]   [ 离开 ]
   ↓ 没有工艺品 → 「你去买点好玩意儿回来再找我」
   ↓ 有钱不够  → 「你先去挣够钱再来」
   ↓ 有工艺品
选一件（列表）→ 扣 500
报真实含金量：
   ≥ 85%       「这个东西很开门啊」
   60–84.9%    「这个东西不错」
   40–59.9%    「这个东西一般般」
   < 40%       「这个啥呀，就一破烂」
   ↓
该件 bAppraised = true → 背包里显示真实含金量
```

## 12. 交互流程 E：卖工艺品

**黑商：**
```
[ 卖工艺品 ] → 「我这可是会验含量的，你小子不要骗我」
   → 选一件 → 数字框报 0–100% → 掷骰（§7）→ 结算
```

**正规买家：**
```
[ 卖工艺品 ] → 必验
   报真实值 → 成交（全价）
   虚报     → 这次收购取消（照 PRD 正规买家规则）
```

## 13. 数据结构（`UstudyGameInstance`）

```cpp
struct FHandicraftItem
{
    int32   CategoryIndex;
    float   NominalGrams;
    float   RealPurity;       // 不可见

{
    FHandicraftItem Item;
    bool    bSold;
    FString BuyerName;

TArray<FShelfSlot>      Shelf;          // 当天 8 件
int32                   ShelfDay = 0;
TArray<FHandicraftItem> HandicraftBag;
```
